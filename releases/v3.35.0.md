# v3.35.0 — Fail-soft runtime flags + per-task caching (2026-10-17)

## Changes

- `runtime_flags.enabled_lenient()`: malformed flag values degrade to the
  documented default with one warning per name. Strict `enabled()` retained
  for startup gates that must fail closed.
- `LiveProgressReporter` caches `AGENT_LIVE_OUTPUT` / `TELEGRAM_STREAM_DRAFTS`
  once per task — a typo no longer fails every task, and the per-tick preview
  no longer re-parses `.env`.
- `tests/test_runtime_flags.py` (strict/lenient/precedence/caching).
- README: both preview flags documented.

## Upgrade

No deps, no migrations; both flags default off. `.env.example` needs the new
`TELEGRAM_STREAM_DRAFTS=0` line added on the host (workspace cannot write
`.env*`). Source release only.
