# OpenCode Bridge v1.8.2

## Stable release-based self-update

- Daily self-update now follows the highest stable semantic-version release tag from the trusted `Alaa91H/opencode-bridge` repository instead of deploying untagged `main`.
- Detached HEAD is now the expected production state because `scripts/deploy.sh` deploys immutable release commits.
- The updater validates the selected release in a temporary detached worktree before activation.
- Tracked local changes, divergent/newer local history, and untracked paths that collide with release files still block the update.
- Non-conflicting untracked files and existing Git stashes are preserved.
- The updater refuses to move the deployment while the queue check reports active work.

## Telegram cleanup carried forward

- Includes the v1.8.1 removal of the free-points indicator and all local quota-tracker plumbing.
- Telegram final responses contain only the actual result body.

## Safety

- No force reset, Git clean, or destructive local-history rewrite is used.
- Release tags must belong to trusted `origin/main` history.
- CI, Code Quality, and Supply Chain Security gate this release.
