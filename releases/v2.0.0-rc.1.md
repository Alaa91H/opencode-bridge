# OpenCode Bridge v2.0.0-rc.1

نسخة تجريبية للاختبار على الخادم قبل إغلاق T50 النهائي.

## ما تتضمنه

- جميع مراحل OpenCode Bridge 2.0 المنفذة حتى T49.
- Durable queue، scheduler v2، drafts، streaming، attachment/media pipeline، OpenCode client v2.
- execution profiles، sandbox/workspace isolation، resource scheduling، cancellation، progress، long-output delivery.
- Telegram UX v2، user preferences، metrics/tracing/logging/health.
- backup/restore، atomic deployment، migration rollback، security hardening، secrets، supply-chain gates.
- v1.8 → 2.0 migration tooling وcanary policy.
- إزالة مؤشر «النقاط المجانية المتبقية» و«استهلاك هذا الأمر» بالكامل من Telegram runtime.

## مهم

هذه **Pre-release** وليست v2.0.0 النهائية. الـsoak النهائي 24–72h ما زال يعمل على main، لذلك لا تعتبر هذه النسخة إغلاقًا لـT50.

## الرجوع إلى Stable

إذا واجهت مشكلة، ارجع إلى أحدث stable release (حاليًا v1.8.2) باستخدام checkout detached للـtag المستقر ثم أعد تشغيل الخدمة.
