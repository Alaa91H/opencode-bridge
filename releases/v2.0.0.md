# OpenCode Bridge 2.0.0

OpenCode Bridge 2.0 introduces the durable task platform architecture completed through T00-T50.

## Highlights

- Durable SQLite-backed queue, leases, heartbeats, retries, DLQ and idempotency.
- Timezone/DST-aware scheduler with misfire and overlap policies.
- Persistent drafts, attachment storage, chunked streaming and media pipelines.
- OpenCode client v2, circuit breakers, model routing and context management.
- Execution profiles, sandboxing, workspace isolation and resource scheduling.
- Real cancellation, persisted progress, lossless long-output artifacts and Telegram UX v2.
- User preferences, metrics, distributed tracing, structured logs and health/readiness.
- Online backups, atomic deployment, migration rollback and hardened secrets/security.
- Supply-chain scanning, SBOM/attestations and progressive quality gates.
- v1.8 → 2.0 migration, canary rollout and fail-closed release evidence.

## Upgrade

Take a verified database backup first. Run the v1.8→2.0 migration in dry-run mode and review its report before applying. Use the canonical `opencode.json`; the legacy `opencode-v3.json` compatibility file has been removed after migration/reference checks.

## Release gate

The v2.0.0 release is published only after the full CI/security/quality gates and a real 24–72 hour endurance soak have passed.
