# v3.38.0 — Deadline-bounded PDF extraction (2026-10-17)

## Changes

- `MediaAnalysisService`: media tools run in a worker thread under
  `asyncio.wait_for` (45s), with a 30s subprocess timeout on the tool
  itself. PDF text becomes a bounded, document-ordered excerpt sharing the
  in-process caps.
- `PdfProcessor(timeout=…)` is now injectable (default 120).
- `TaskExecutionService` merges both representation sets for the prompt,
  the part-exclusion decision and one audit event.
- `tests/test_media_analysis_service.py` + two wiring tests.

## Failure policy

Missing tool, non-zero exit, wedged tool, or a scanned PDF with no text layer
produce **no** representation. Nothing is guessed, and nothing is installed.

## Upgrade

No deps, no migrations. Needs `pdftotext` already present to have any effect;
without it behaviour is unchanged. Source release only.
