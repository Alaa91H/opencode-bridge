# OpenCode Bridge v2.0.0-rc.6

نسخة تجريبية، تضيف بوت تنزيل الملفات المُدار فوق حد الـ 2000MB.

## الاستعمال

`
/download https://example.com/file.pdf
`

الملف بينزل، بينحفظ، وبيترسل كملف تيليجرام إذا كان أصغر من 50MB. الأكبر بينسجّل باللوحة. كل شيء بينظّف تلقائيًا بعد 24 ساعة.

/menu ← «الملفات والتنزيلات»: القايمة، الحدود الفعلية، المساحة المتاحة، والإرسال والحذف.

## حماية SSRF

الخادم بيعمل طلب نيابة عنك، فالرابط مدخل موثوق. قبل أول بايت:

- المخطط http/https بس
- العناوين loopback وprivate وlink-local وreserved مرفوضة
- localhost و.local مرفوضين
- **كل عنوان محلول** بيتفحص، مو المكتوب بس
- **سلسلة إعادة التوجيه** بتتفحص بعد وصول الرد

169.254.169.254 (بيانات وصف المضيف) و10.0.0.119 (الخادم نفسه) محجوبين.

## الحدود

| | |
|---|---|
| حد الملف | 2000MB |
| ميزانية مجمّعة | 8GB |
| مدة الحفظ | 24 ساعة |
| الإرسال المباشر | 50MB |
| التنظيف | كل 15 دقيقة |

كل الملفات بمجلدات لكل مالك، والفهرس بصلاحيات 0600. أي ملف بينكتب .part أول، وأي فشل بيشيله.

## بدون تبعية جديدة

equirements.txt مقيّد بثلاث حزم، فالتنزيل بـ httpx. استخراج الفيديو عبر yt-dlp اختياري: إن موجود على الخادم بيشتغل، وإن لأ اللوحة بتقول ذلك بوضوح بدل ما تَعِد بشي ما في.

## 18 اختبار

على خادم HTTP حقيقي: تنزيل حقيقي ومطابقة بايتات، عزل المالكين، رفض 8 أنواع SSRF، حدود الحجم، إزالة الملف الناقص، تنقية الأسماء، التنظيف، والفهرس التالف.
