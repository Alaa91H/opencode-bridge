# وضع إيقاف التحديثات الطارئ — T09

يوفر Bridge وضع `emergency-stop` في لوحة Server → Updates للمالك داخل محادثة Telegram الخاصة. الإجراء يوقف نشر Bridge الآلي واليدوي، وتحديث OpenCode اليدوي، وتحديث نظام التشغيل اليدوي، بالإضافة إلى إجراءات الصيانة المؤثرة المجدولة عبر root.

عند التفعيل يعطل النظام أيضًا ملف التوافق السابق `auto-update-enabled` وملف موافقة تحديث النظام `host-auto-update-enabled` قبل حفظ الوضع؛ لكيلا يؤدي رجوع إصدار قديم أو انقطاع أثناء الحفظ إلى إعادة تفعيل تحديثات آلية غير مقصودة.

يمكن فحص الحالة بأداة `python scripts/host-inventory.py`. للخروج من الإيقاف الطارئ اختر وضعًا آخر بوضوح من لوحة الإدارة. تفعيل تحديثات Ubuntu يتطلب موافقة جديدة منفصلة بعد الخروج.

**الحدود:** إيقاف التحديثات والصيانة المجدولة ليس إيقافًا لكل مهام البوت أو كل الإجراءات الإدارية؛ ولا يعزل الوكيل أو يقفل شبكة الخادم. لا يعد هذا شهادة T09 أو T18؛ تتطلب الشهادة اختبارًا على staging والفحص من systemd.

اختبار CI يتحقق من رفض تشغيل عمليات root عند وضع الإيقاف ومن رفض عمليات التحديث اليدوية قبل تنفيذ subprocess، بدون إجراء تحديثات نظام حقيقية.
