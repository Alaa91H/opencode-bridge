# اختبار استعادة age الحقيقي باستخدام بيانات تجريبية

أضيف اختبار تكاملي يجهز قاعدة SQLite اختبارية وهوية age مؤقتة، ويُنشئ نسخة مشفرة، ويفك تشفيرها، ويستعيد نسخة قاعدة SQLite في مجلد معزول، ثم يفحص القيمة المحفوظة ورفض التلاعب بالملف.

لا يستخدم هذا الاختبار مفاتيح أو قواعد بيانات الإنتاج.

## التشغيل على بيئة اختبار Linux تحتوي على age وage-keygen

```bash
AGE_RECOVERY_REQUIRED=1 python -m unittest discover -s tests -p 'test_real_age_backup_recovery.py' -v
```

تُعد نسخة age الحقيقية مطلوبة عند وجود المتغير AGE_RECOVERY_REQUIRED=1. أما في بيئات Python التي تفتقر إلى أداة age، فإن الاختبار يُتجاوز ولا يقدم إثباتاً لفك التشفير. لذلك لا يعتبر نجاح باقي CI شهادة استعادة مشفرة حقيقية حتى تُشغَّل هذه الخطوة إلزامياً داخل بيئة staging/CI مجهزة.

لا تزال تجربة استعادة نسخة إنتاج حقيقية بمفتاح خارجي وخطة rollback وقياس RPO/RTO وتوافق WAL والمهام غير منجزة.
